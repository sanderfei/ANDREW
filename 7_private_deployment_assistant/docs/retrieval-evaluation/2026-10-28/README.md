## 扩展样本与请求数量

- 322条唯一正例问题：原30题＋新增269题＋23条环境过滤题，覆盖全部198份已入库来源。
- 24条无答案观察题：域外问题与缺少现场证据的问题分开解释；不进入Hit、MRR、Recall分母。
- 正例每题重复3次，共966次候选执行用于计时和稳定性检查，独立样本量仍是322。
- 实际HTTP检索349次＝3次暖身＋322次正例＋24次负例；本地候选查询993次，另有10次检查开销消融查询。六方案共享候选，不是六倍独立数据库请求。
- 322题的API与进程内Dense排序完全一致；各方案跨三次重复的排名和指标稳定。23条过滤题的参考来源与所有返回来源都满足实际索引元数据过滤。
- 问题由助手依据文档构造和核对，保留章节与短依据；不是独立真实用户盲测，也没有独立人工穷尽相关性标注。
- 标注以主要相关文档为单位。每题单来源使Recall@5与Hit@5相同；其他未标注文档可能同样有用。命中不等于答案正确或故障恢复。

## 已确认现象与分析边界

1. **首轮100%不能外推**：BM25从首轮30/30变为扩展300/322，去重后301/322。精确报错题49条全部命中，但少上下文题15条仅10条命中。
2. **等权融合确有退化**：相对BM25去重，混合去重丢16题、另救3题，净少13题；不能默认两路融合一定优于单路。完整ID列表见[分析JSON](expanded.analysis.json)。
3. **重复来源占位置**：混合Top5平均仅约3.67个不同来源，按来源去重使272/322提升到288/322。去重不能保证一个片段就包含该案例全部必要证据。
4. **标签遗漏与排序失败要区分**：`expanded-REG-12-a`未命中指定的REG-12，但返回OBS-21也包含Zot/Harbor分流资料。本轮分数按原标签保留，不把它简单等同于完全无有用资料。
5. **上下文字符数没有自然下降**：原Dense平均3292字符、BM25去重3672字符、混合去重3473字符；这不是Token计数，不能声称已经降低聊天Token或改善生成答案。
6. **无法由邻近分数直接确认可回答**：24条观察题全部获得近邻；负例最高分范围0.1362～0.5848，正例范围0.3645～0.7358，明显重叠。域内负例可能命中背景资料，但仍缺实时现场证据，不是已测出可靠拒答阈值。

## 延迟消融

首轮固定向量下，全量统计＋查询P50 15.29ms，轻量检查＋查询4.12ms。扩展运行的同类5次配对观察为24.21ms和5.86ms，返回ID相同。扩展全量组有一次约100ms的尾部样本；每组只有5次，不能作为稳定SLA或准确加速倍数。
API完整HTTP耗时与此项不同层，尚未把生产接口改成轻量检查，也未证明整个API已降到4～6ms。

## 可优化项（先记录，未替换业务算法）

| 优先级 | 事项 | 依据 | 后续验证方式 |
| --- | --- | --- | --- |

| P0 | 补多相关来源标签与欠限定题复核 | REG-12/OBS-21重叠，4条问题缺必要限定 | 独立复核真实用户题，冻结开发/留出集，保留旧版本分数 |
| P1 | 记录完整Top20、两路排名与RRF分项贡献 | 当前只存最终Top5，尚不能精确归因16条融合退化 | 保持参数不变，增加只读诊断字段和来源级排名解释 |
| P1 | 比较来源聚合后融合、词法优先与不同权重 | 去重救回16题，等权融合净少13题 | 在开发集选择策略，冻结后评估独立留出集，不在本322题上反复调参后宣称泛化 |
| P1 | 非模型术语归一化与标题/组件字段实验 | stdin/标准输入、VIP/浮动IP、storageClassName/存储类等表达差异 | 每次只加一种变体，保留原文与精确报错，独立统计口语题和误召回 |

| P2 | OCR与资料治理 | DOCX有50张图片未处理，coverage说明也在业务索引内 | 先标注图片独有问题；比较是否排除目录/历史覆盖统计文档 |
| P2 | 连接复用、检索缓存和上下文预算 | API与进程内时间差包含多环节，不能全归因于向量查询 | 先逐阶段计量；缓存键包含环境、模型及知识库版本 |

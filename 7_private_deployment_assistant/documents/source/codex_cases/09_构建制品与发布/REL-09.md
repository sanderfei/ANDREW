# REL-09：Chart应用版本与镜像tag升级不能仅看包名

项目：g_kube_installer / g_web_installer。记录状态：源码结论。来源会话起始日期：2026-04-13, 2026-08-04, 2026-09-21（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## REL-09 问题与表现

neo4j5.3.0被当成5.26.28旧/新关系，或只改tag而入口/挂载不适配。

## REL-09 最终根因或已确认边界

Chart.version、appVersion、镜像tag是三项；Chart5.3.0可运行Neo4j5.26.28，也曾另有官方Neo4j5.3.0分支。

## REL-09 处理方案

以最终渲染镜像及容器真实版本判断，查对应日期/分支。换Bitnami/官方镜像时同时适配入口、目录、资源、探针、NodePort及旧PVC，业务数据库不能自动降级。保留旧初始化数据和参数时逐组件验证。

## REL-09 验证证据与限制

历史tgz/Git版本定位，部分分支新安装验证通过；不会把历史中间版本当当前统一版本。

以上为历史归档结论，本次仅整理文档，未重新连接客户环境、部署或触发业务操作。

## WEB-09 问题与表现

某用户登录后网关列目录返回TOKEN_INVALID，而其他用户正常。

## WEB-09 最终根因或已确认边界

普通网关请求同时带应用与IAM用户Header，错误本身不指明哪一项失效；可能是浏览器旧会话、IAM环境、代理头或账号授权。

## WEB-09 处理方案

定位实际失败请求URL/RequestID和会话建立时间，内层重新登录后重试，核对同一应用与用户凭据来源/tenantId。不能在长期上传中仅凭固定时间推断JWT过期；记录必要诊断字段但不归档原始Header。

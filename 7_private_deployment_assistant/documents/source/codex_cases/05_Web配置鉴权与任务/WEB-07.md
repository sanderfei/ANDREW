# WEB-07：IAM401应用授权与实际网页应用不一致

项目：g_web_installer。记录状态：历史功能验证。来源会话起始日期：2026-09-15（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## WEB-07 问题与表现

v3 IAM返回401及411003/21007授权不足，但相同账号网页登录成功。

## WEB-07 最终根因或已确认边界

当轮失败请求的应用身份为ops，而网页使用DigiwinCloud；不能先断言用户没有企业权限。

## WEB-07 处理方案

对照成功网页的应用身份、请求tenantId、登录字段与IAM环境，使用匹配应用授权再验证。应用凭据由登录请求传入，IAM返回用户凭据，后端会话供后续网关双Header使用；不把凭据写JWT可读payload或本知识库。

## WEB-07 验证证据与限制

匹配网页请求后IAM200、buckets200及真实对象列表返回；原始失败仅针对错误应用。

# WEB-03：组件卸载SSH旧指纹和私钥支持缺失

项目：g_web_installer。记录状态：代码已验证。来源会话起始日期：2026-07-29, 2026-07-31（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## WEB-03 问题与表现

接口SSH正常但UninstallComJob报REMOTE HOST IDENTIFICATION HAS CHANGED或只有密码认证失败。

## WEB-03 最终根因或已确认边界

卸载走生成脚本+系统SSH，与接口GoSSH客户端不同；旧known_hosts和写死root:22/sshpass导致差异。

## WEB-03 处理方案

历史脚本优先ssh -i PrivateKeyPath，否则环境方式密码认证，透传用户/端口，保留PID日志链。历史还改为独立known_hosts策略避免旧记录；用于新环境前应确认主机身份。人工恢复先从可信渠道核对指纹，再仅移除旧节点记录，不删除整份known_hosts。

## WEB-03 验证证据与限制

临时测试/包检查通过，随后提交和121发布记录；不宣称当轮所有卸载任务均实测。

# WEB-05：users.json更新后权限不生效

项目：g_web_installer。记录状态：历史功能验证。来源会话起始日期：2026-08-12, 2026-09-15（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## WEB-05 问题与表现

运行时修改用户权限但服务仍使用启动时权限；切换用户列表后看不到目录。

## WEB-05 最终根因或已确认边界

旧sync.Once只加载一次，或编辑的是仓库configs/users.json而非服务data/config/users.json。

## WEB-05 处理方案

历史改监控运行目录Write/Create/Remove/Rename、短debounce与RWMutex整表替换。缺失/非法JSON按deny-all处理，未知用户保持nil,false语义。确定实际运行路径后更新，不能将API认证成功当作业务数据权限已授予。

## WEB-05 验证证据与限制

行为/race验证；历史121初始化210用户日志确认热加载且进程未重启。210只属于当时数据。

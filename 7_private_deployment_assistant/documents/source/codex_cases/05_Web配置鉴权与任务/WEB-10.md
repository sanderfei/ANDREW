# WEB-10：runningProcesses并发注册和kill存在数据竞争

项目：g_web_installer。记录状态：代码已验证。来源会话起始日期：2026-07-10（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## WEB-10 问题与表现

异步任务注册、自然退出与多个kill请求同时访问进程map，可能并发异常。

## WEB-10 最终根因或已确认边界

旧全局注册表访问未统一互斥，kill与退出清理会竞争。

## WEB-10 处理方案

历史统一注册/注销/查询互斥，kill原子取走进程，真正Kill放锁外；重复请求安全无操作。该修复只处理map一致性，不能等同进程组终止/KK子进程清理已实现。

## WEB-10 验证证据与限制

临时race测试覆盖注册/注销/竞争kill通过并删除。

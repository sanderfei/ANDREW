# KK-C03：Calico等待逻辑目标数错误及无法持续轮询

项目：g_kube_installer。记录状态：待验证。来源会话起始日期：2026-04-15, 2026-04-27（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## KK-C03 问题与表现

calico 实际已启动却等待超时；日志数值与集群节点数量不一致。

## KK-C03 最终根因或已确认边界

历史等待代码错误计算 master/worker 去重数量、采用严格等于等条件，另有一次读取后 select 只等待 context 超时的缺陷。组件前置检查会放大问题。

## KK-C03 处理方案

按真实 DaemonSet desiredNumberScheduled/可就绪节点判定，正确合并角色节点，允许已就绪数满足目标，并确保每轮有可取消的等待和重新查询。保留用户最终限定的结构；也须单独查 Calico 实际 Ready，不能把所有 0 Ready 都解释为等待误报。

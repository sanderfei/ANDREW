# KK-O15：两个离线集群复用同一个registry

项目：g_kube_installer。记录状态：源码结论。来源会话起始日期：2026-10-13（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 offline。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## KK-O15 问题与表现

第二个集群是否必须重复 init registry 和 push images；同名仓库域名是否互相覆盖。

## KK-O15 最终根因或已确认边界

复用取决于镜像版本/架构齐全、网络/DNS/TLS/认证一致及节点配置，而不是 registry 属于哪一个集群。Web 容器 /etc/hosts 中同一域名只有统一解析目标；两个不同仓库共用域名会造成后任务改映射影响前任务。

## KK-O15 处理方案

共享同一个真实仓库时统一指向同一个 IP，补推缺失镜像后跳过重复初始化/推送，仍为第二集群准备匹配 artifact。若两个独立仓库，应规划不同域名及对应证书、配置和镜像引用，或分离执行环境。不要让一个公共域名按任务不断换 IP。

## KK-O15 验证证据与限制

2026-10-13 两次源码回复确认复用与 hosts 覆盖：Web 容器后续访问受影响，但不会同步修改第一个集群节点自身的 hosts。未做现场双集群复用试验。

# OBS-15：OBS网关目录重命名不是文件系统mv

项目：g_web_installer。记录状态：历史功能验证。来源会话起始日期：2026-09-29（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## OBS-15 问题与表现

需要folder rename，误以为对象存储有原子目录移动。

## OBS-15 最终根因或已确认边界

目录是key前缀，工具或网关可能封装批量copy/delete，不能假设与本地rename一致或无中间状态。

## OBS-15 处理方案

历史确认 obsutil 支持普通对象桶目录移动：mv 源前缀/ 目标前缀/ -r -flat，-dryRun 预演，-f 跳过确认；不是 -y。检查源/目标和逐对象结果，残留可能是空目录标记。新网关也可封装移动，但不是相同执行链；PFS需另核对。

## OBS-15 验证证据与限制

历史命令报告16对象成功、0失败，transferred size0B不表示失败；大目录原子性或失败补偿没有完整证明。

# HELM-29：Neo4j默认资源被Web低值覆盖触发Chart校验

项目：g_kube_installer。记录状态：代码已验证。来源会话起始日期：2026-08-04, 2026-08-12（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## HELM-29 问题与表现

Helm提示Neo4j请求资源低于要求；Chart里500m/2Gi但实际命令100m/256Mi。

## HELM-29 最终根因或已确认边界

Web后端组件默认值被KK--set注入并覆盖正确Chart值，不是前端自主默认。

## HELM-29 处理方案

历史后端默认改CPUrequest500m/limit1000m，内存request2Gi/limit4Gi；检查实际请求、保存YAML和渲染值。还需节点可调度资源满足，参数合法不等于有容量。

ebc3d23历史提交及专项实际验证配置；不代表所有集群该值都合适。

# BK-11：MongoDB过滤误用mongodump不支持的ns参数

项目：g_web_installer。记录状态：代码已验证。来源会话起始日期：2026-07-10（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## BK-11 问题与表现

白/黑名单备份传--nsInclude/--nsExclude给mongodump报错。

## BK-11 最终根因或已确认边界

这些恢复过滤参数不能直接用于当前mongodump；先全量导出再删除黑名单也浪费资源并有语义边界。

## BK-11 处理方案

最终先查询实时库列表并验证白名单存在，再逐选中库mongodump--db--out。全量保留原生.archive.gz，过滤目录模式产.tar.gz并用匹配mongorestore恢复；local不可作为库过滤。不得把tar包装作Mongo archive。

## BK-11 验证证据与限制

执行级白/黑名单临时测试、包编译通过；后续121真实回归见系统集合案例。

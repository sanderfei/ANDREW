# BK-13：数据库列表空数组因kubectl exec未传stdin

项目：g_web_installer。记录状态：历史功能验证。来源会话起始日期：2026-07-10（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## BK-13 问题与表现

MongoDB/MariaDB/Neo4j列表[]但库确实存在；Defaulted container日志混入库名。

## BK-13 最终根因或已确认边界

heredoc传sh-s时缺kubectl exec-i，stdin为空导致shell正常exit0；默认容器提示来自stderr不是数据库。

## BK-13 处理方案

为接收脚本的MongoDB、MariaDB、Neo4j分支加exec-i并显式-c实际容器，分离stderr/业务输出。查询失败返回真实错误，不能伪装[]。ES/Milvus不走同款heredoc，无需机械添加。

## BK-13 验证证据与限制

214无-i空输出/带-i有库名对照，121正式五目标列表回归通过。

以上为历史归档结论，本次仅整理文档，未重新连接客户环境、部署或触发业务操作。

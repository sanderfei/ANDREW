# BK-18：MongoDB导入包伪装tar.gz且多套一层目录

项目：g_web_installer。记录状态：待验证。来源会话起始日期：2026-05-21, 2026-08-27（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## BK-18 问题与表现

gzip stdin has more than one entry，tar退出2；网络恢复后导入仍失败。

## BK-18 最终根因或已确认边界

实际文件是ZIP却叫mongo_dump.tar.gz，且mongo_dump外包了一层业务目录。文件名不是格式证明。

## BK-18 处理方案

用file/tar-t核对，真实重新打包顶层mongo_dump/，数据库目录下放未gzip的BSON和metadata。该导入器使用目录模式，不能直接拿mongodump--archive或--gzip。改扩展名不能改格式，旧备份原生archive与前端导入包要区分。

### BK-18 命令示例

在对应执行环境替换占位符，先核对版本/路径；本文件没有执行这些命令。

```bash
file mongo_dump.tar.gz
tar -tzf mongo_dump.tar.gz | head
# 在已有正确 mongo_dump 目录的父目录执行
tar -czf mongo_dump.tar.gz mongo_dump
```

121实际file识别和目录结构已确认；最终数据库恢复没有记录。

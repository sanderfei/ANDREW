# BK-09：立即备份trigger传状态对象导致JSON解析失败

## BK-09 问题与表现

立即备份请求报类型错误，trigger带installed/status/next_run_at对象。

## BK-09 最终根因或已确认边界

BackupRunRequest.Trigger是string，前端将singleConfig.status整个状态对象作为trigger。请求在解析阶段失败，尚未触发etcd备份。

## BK-09 处理方案

请求使用{"trigger":"manual"}或{}；空值归一manual。状态响应字段不作为备份输入。只需修请求，不应改etcd连接或新增备份等待。

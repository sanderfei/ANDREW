## BK-22 问题与表现

schema_update.sql包含Schemas are synced, no changes to be made.，执行失败。

## BK-22 最终根因或已确认边界

Atlas默认diffstdout混入人读状态文字，不能直接作为可执行SQL。

## BK-22 处理方案

历史强制schema diff --format SQL-only，避免拼普通状态文字；核对计划文件不含临时库名/错误DDL。prepare生成计划，apply才修改业务库，restore是另一路，不把三步混为自动覆盖。

# BK-25：Velero迁移Kubernetes资源不自动备份所有NFS文件

项目：g_web_installer。记录状态：源码结论。来源会话起始日期：2026-05-15, 2026-07-23（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## BK-25 问题与表现

以为Velero/etcd快照能把整个集群及所有业务数据直接迁到另一个集群。

## BK-25 最终根因或已确认边界

etcd保存Kubernetes元数据，不包含数据库卷内字节；Velero资源/PV快照/文件系统备份需要不同后端，已有NFS数据不因资源导出自动打包。

## BK-25 处理方案

分别定义目标集群重建、Kubernetes资源恢复、PV数据/数据库一致性、外部服务依赖。明确NFS是否配置文件系统备份/独立同步，再做恢复验证；不要用etcd snapshot代替应用备份。

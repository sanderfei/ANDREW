# BK-19：MariaDB和Elasticsearch导入包合同不匹配

项目：g_web_installer。记录状态：源码结论。来源会话起始日期：2026-08-27, 2026-09-01（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## BK-19 问题与表现

多SQL顺序不确定；ES普通JSON数组、snapshot/Kibana导出当NDJSON导入。

## BK-19 最终根因或已确认边界

当前v2导入器按固定包名与具体工具格式解释，不会自动支持任何数据库导出。历史ES导入逻辑曾要求9.1.2，而后续KK插件需求回7.15，版本合同需重新核对。

## BK-19 处理方案

MariaDB包mariadb_data.zip用单个自含CREATE DATABASE/USE的SQL。ES elastic_data.tar.gz用<index>.json NDJSON及可选matching mapping/settings，顺序settings→mapping→data，不混入无关JSON。部署7.15时必须先确认/适配Web版本检查，不能默认历史9.x导入器兼容。

## BK-19 验证证据与限制

历史格式合同源码确认，非本条现场导入证明。

# BK-04：Milvus备份名称前缀与字符限制

项目：g_web_installer。记录状态：历史功能验证。来源会话起始日期：2026-06-01, 2026-06-05（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## BK-04 问题与表现

milvus-backup check成功，create报invalid backup name。

## BK-04 最终根因或已确认边界

工具0.5.x名称只接受字母/下划线开头及字母数字下划线；数字开头或含-的通用backupID不合法。

## BK-04 处理方案

仅将Milvus内部名称规范为合法格式，如milvus_20260604_210101_milvus，保留Web外部backupID与记录关联。不要把KubernetesRFC1123命名要求套给Milvus工具，二者规则相反。同步生成脚本和手工脚本。

## BK-04 验证证据与限制

121改内部名字实跑成功，tar包含binlogs/insert_log；包测试和bash-n通过，当轮未部署正式server。

# BK-06：备份warning是最近任务失败不是组件健康

项目：g_web_installer。记录状态：历史功能验证。来源会话起始日期：2026-07-20, 2026-07-28（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## BK-06 问题与表现

Neo4j/Milvus服务正常，备份页仍warning或last backup failed。

## BK-06 最终根因或已确认边界

备份状态综合配置、cron、running、records和最近history；最新失败晚于最新成功会warning，代码发布不清除历史记录。

## BK-06 处理方案

分别看组件Ready/API与最近备份PID日志。修复部署后需真实新成功备份覆盖，或等待下一次计划；配置保存/校验不会产生新备份记录。normal也不证明备份归档数据可恢复。

## BK-06 验证证据与限制

历史Neo4jRETURN1成功、服务Ready但旧任务失败；没有擅自触发会停库的备份。

# BK-05：Milvus备份141因awk早退触发SIGPIPE

项目：g_web_installer。记录状态：历史功能验证。来源会话起始日期：2026-06-08（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## BK-05 问题与表现

备份日志只到SSH提示便exit status141，未见Milvus业务错误。

## BK-05 最终根因或已确认边界

set-euo-pipefail下kubectl get pod | awk ... exit提早关管道，上游SIGPIPE；抓到pod名也会整管道失败。

## BK-05 处理方案

优先label/jsonpath精确选standalone与MinIO，fallback不提前exit。使用实际label(component=standalone/app=minio)，保持明确错误而非忽略所有管道错误。部署后触发新备份才能覆盖历史failed状态。

## BK-05 验证证据与限制

214旧命令30轮可复现，修复选择命令30轮稳定；后续121确认新代码，调度时区另为未生成记录原因。

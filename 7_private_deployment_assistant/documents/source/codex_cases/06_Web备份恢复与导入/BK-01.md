# BK-01：backup config零字节导致unexpected end of JSON input

项目：g_web_installer。记录状态：历史功能验证。来源会话起始日期：2026-08-31（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## BK-01 问题与表现

/backups/targets失败，failed to parse backup config: unexpected end of JSON input；没请求也持续警告。

## BK-01 最终根因或已确认边界

缺文件能初始化，但既存零字节/空白config.json进入json.Unmarshal失败；调度器扫描也读取它。必须先确认进程cwd与容器映射，不能在宿主错误目录找文件。

## BK-01 处理方案

仅在确认目标文件为空且无需恢复旧策略时保留故障文件，原子写入{}让后端合并默认配置，不必重启/改代码。该操作不是恢复丢失策略；实际有旧策略应先找可用备份。代码持久写入可另做临时文件+sync+rename加固。

## BK-01 验证证据与限制

历史现场修为{}后生成有效JSON、7项disabled目标；未重启。文件为何截断的根因未闭环。

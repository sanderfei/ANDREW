# BK-15：Neo4j3.5不支持SHOW DATABASES及sh执行Bash数组

项目：g_web_installer。记录状态：历史功能验证。来源会话起始日期：2026-07-10, 2026-07-20（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## BK-15 问题与表现

Neo4j过滤列库为空，helper报sh:Syntax error:( unexpected。

## BK-15 最终根因或已确认边界

旧3.5只有graph.db路径而非新SHOWDATABASES；脚本DATABASES=()是Bash语法却由/bin/sh执行。

## BK-15 处理方案

按实际Neo4j版本列库并兼容graph.db，helper改POSIX逐行文件读取、stdin正确传递。过滤为空时在缩容前失败。不要假定只升级主程序即可让旧helper兼容。

## BK-15 验证证据与限制

1213482e2c真实graph.db白名单dump成功，排除唯一库在停库前拒绝，副本恢复1/1。

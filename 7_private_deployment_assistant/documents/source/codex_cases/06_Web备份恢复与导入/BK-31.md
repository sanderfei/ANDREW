# BK-31：备份配置接口接受只有目录没有cluster config的伪集群

项目：g_web_installer。记录状态：代码已验证。来源会话起始日期：2026-05-25（含之后续问，不是本次现场检查日期）。

适用标签：Kubernetes any；系统 any；安装模式 any。any 表示历史证据未限定，需按实际版本再次核对；不是承诺所有环境兼容。

## BK-31 问题与表现

对仅创建data/cluster目录的名字调用备份接口，生成策略但真正运行无法取Master。

## BK-31 最终根因或已确认边界

旧ensureClusterExists只检查目录，未检查config.yaml。

## BK-31 处理方案

历史增加同时校验目录和config.yaml，错误集群同步失败，避免产生无意义备份状态。识别集群仍不代表其SSH/数据库就绪。
